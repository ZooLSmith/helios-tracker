Open or share the map

A few questions, and the best way to open or share the map for what you want.

Who should see the map?

  • Just me, on this PC
  • Me, on another device at home
  • Me, without leaving the game
  • In my stream, for viewers
  • People elsewhere, in their own browser

Who's watching?

  • A few friends I choose
  • My stream's viewers, up to about 50
  • More than 50 viewers

Which suits you?

  • I have a domain on Cloudflare
  • Signing in once with Google, Microsoft, GitHub or Apple is fine
  • Nothing to sign up for

Open it on this PC

In the mod's options, press Open Map in Browser, or go to this address in any browser on the gaming PC:

http://localhost:8777/

See Install.

Your local network

Any device on the same network as the gaming PC can open the map: a phone, a tablet, another PC. Nothing leaves your home network.

  1. Allow LAN access

    Turn on Allow LAN Access in the mod's options. With it off, only the gaming PC can open the map.

  2. Find the gaming PC's address

    On the gaming PC, open Windows Settings, Network & internet, then the Wi-Fi or Ethernet connection it's using, and note its IPv4 address. Or type ipconfig in Command Prompt or PowerShell: it's the IPv4 Address line.

  3. Open it on the other device

    On the phone or the other PC, connected to the same network, type http:// followed by that address and :8777/ in the browser.

The firewall

Windows may ask whether to let the game through its firewall: allow it on private networks. If you said no before, the other device can't connect: allow the game in Windows Defender Firewall, Allow an app through firewall.

The Steam overlay

Press Shift+Tab in game, open the Web browser and go to this address:

http://localhost:8777/

The overlay's browser has no zoom: use the Size under Panels in the page's Settings instead.

An OBS overlay

The map in a scene, over your game, with its background see-through. Viewers see it in the stream: nothing to share.

  1. Add a browser source

    Add a Browser source with the URL http://localhost:8777/.

  2. Reach the page

    Right-click the source and choose Interact.

  3. Make it see-through

    In the page's Settings tab, under Map, lower Background to 0 %. The scene now shows through, with only the level's shape and the markers left. The Map slider and the Opacity under Panels fade the rest.

The page remembers its settings per browser, so the OBS source keeps its own look apart from your normal browser.

Tailscale Funnel

A public HTTPS address that stays the same: anyone with it opens the map, with no account and nothing to install on their side.

  1. Install Tailscale

    Install Tailscale on the gaming PC and sign in.

  2. Open the funnel

    Run this in a terminal. The first time, it gives a link to turn Funnel on for your account:

    tailscale funnel 8777

  3. Share the address

    It prints your address: https:// then your PC's name on ts.net. It stays the same every time.

Details: Tailscale Funnel.

Optional: start it automatically with the map
  1. In sdk_mods, open the .helios_tracker folder (the mod creates it the first time the game runs with it) and create a text file named autoexec.ps1 in it.
  2. Paste this line in it: 
    tailscale funnel $env:HELIOS_PORT
  3. From now on the tunnel starts with the map, and stops with it.

A Cloudflare tunnel

A named tunnel publishes the map on your own domain, like map. and your domain, with HTTPS.

  1. Install cloudflared

    Install cloudflared on the gaming PC (or, in a terminal: winget install Cloudflare.cloudflared).

  2. Create the tunnel

    In Cloudflare's dashboard, create a tunnel and give it a hostname on your domain.

  3. Run it

    On the gaming PC, with your tunnel's name:

    cloudflared tunnel run --url http://127.0.0.1:8777 your-tunnel-name

  4. Share the address

    Your hostname, with https://. It stays the same every time.

Details: Cloudflare Tunnel.

Optional: start it automatically with the map
  1. In sdk_mods, open the .helios_tracker folder (the mod creates it the first time the game runs with it) and create a text file named autoexec.ps1 in it.
  2. Paste this line in it: 
    cloudflared tunnel run --url http://127.0.0.1:$env:HELIOS_PORT your-tunnel-name
  3. From now on the tunnel starts with the map, and stops with it. Use your tunnel's name.

A quick Cloudflare tunnel

No account and no domain: one program and one command.

  1. Install cloudflared

    Install cloudflared on the gaming PC (or, in a terminal: winget install Cloudflare.cloudflared).

  2. Open the tunnel

    Run this in a terminal while the map runs, and leave it open:

    cloudflared tunnel --url http://127.0.0.1:8777

  3. Share the link

    It prints a trycloudflare.com address: paste it here, and share the link you get. Everyone keeps their own settings with it, even though the address changes at every start.

Good for an evening, not for a stream's fixed link:

  • The address changes at every start, and Cloudflare offers quick tunnels for testing, with no guarantee.
  • For the first half-minute after the page opens (and after each refresh), movement comes in bursts; then it's smooth.
Or, with nothing to install: an SSH tunnel

Windows already has ssh. Free services run these tunnels, for example localhost.run. Run this in a terminal while the map runs, answer yes the first time, and paste the https:// address it prints in step 3's box:

ssh -R 80:127.0.0.1:8777 nokey@localhost.run

These are third-party services, not part of Helios Tracker: their free plans have time limits and can change, and a service can close. Like a quick tunnel, the address changes every time: share it through the site too. If it stops working, another SSH tunnel service works the same way: check that its address doesn't contain your IP (some free ones do). Details: localhost.run.

More than 50 viewers

That's beyond what the mod can serve: every viewer gets every update straight from your PC, and your upload runs out long before that.

It needs a relay: a server that receives the map's stream once and sends it on to every viewer, so your PC uploads it only once. Or, for Twitch, an extension that shows the map in the player. Both mean running a service of your own: Helios Tracker doesn't provide one.

Before you share

  • Anyone with the link sees the map, the players' names and their gear.
  • Stop the tunnel when you're done.
  • Allow LAN Access isn't needed: the tunnel connects to the PC itself.
  • Why not just open a port on the router? You can, but the link is then your home IP address: whoever gets it, and whoever they pass it on to, knows it, and while the port is open your PC is reachable from the whole internet on it. The address also changes now and then, and many internet providers don't allow it at all. A tunnel keeps your IP private and the link working.
  • Every viewer uses your upload: your PC sends each of them every update, about 0.6 Mbit/s per viewer (more in busy levels). To go easier on it, lower Tick Rate in the mod's options (10 by default; 5 halves it): the page smooths the movement in between. It applies to everyone, your own page too.
