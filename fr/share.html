Ouvrir ou partager la carte

Quelques questions, et la meilleure façon d'ouvrir ou de partager la carte selon ce que vous voulez.

Qui doit voir la carte ?

  • Moi seul, sur ce PC
  • Moi, sur un autre appareil à la maison
  • Moi, sans quitter le jeu
  • Dans mon stream, pour les spectateurs
  • D'autres gens, ailleurs, dans leur navigateur

Qui regarde ?

  • Quelques amis que je choisis
  • Les spectateurs de mon stream, jusqu'à une cinquantaine
  • Plus de 50 spectateurs

Qu'est-ce qui vous convient ?

  • J'ai un domaine sur Cloudflare
  • Me connecter une fois avec Google, Microsoft, GitHub ou Apple me va
  • Rien à créer

L'ouvrir sur ce PC

Dans les options du mod, appuyez sur Open Map in Browser, ou allez à cette adresse dans n'importe quel navigateur du PC de jeu :

http://localhost:8777/

Voir Installation.

Votre réseau local

Tout appareil sur le même réseau que le PC de jeu peut ouvrir la carte : un téléphone, une tablette, un autre PC. Rien ne sort de votre réseau.

  1. Autoriser l'accès réseau

    Activez Allow LAN Access dans les options du mod. Désactivée, seul le PC de jeu peut ouvrir la carte.

  2. Trouver l'adresse du PC de jeu

    Sur le PC de jeu, ouvrez les Paramètres Windows, Réseau et Internet, puis la connexion Wi-Fi ou Ethernet qu'il utilise, et notez son Adresse IPv4.

  3. L'ouvrir sur l'autre appareil

    Sur le téléphone ou l'autre PC, connecté au même réseau, tapez http:// suivi de cette adresse et de :8777/ dans le navigateur.

Le pare-feu

Windows peut demander s'il faut laisser passer Borderlands 2 par son pare-feu : autorisez-le sur les réseaux privés. Si vous avez refusé, l'autre appareil ne peut pas se connecter : autorisez le jeu dans Pare-feu Windows Defender, Autoriser une application via le pare-feu.

L'overlay Steam

Appuyez sur Maj+Tab en jeu, ouvrez le Navigateur web et allez à http://localhost:8777/.

Le navigateur de l'overlay n'a pas de zoom : utilisez la taille de l'Interface dans les Réglages de la page.

Un overlay OBS

La carte dans une scène, par-dessus votre jeu, au fond transparent. Les spectateurs la voient dans le stream : rien à partager.

  1. Ajouter une source navigateur

    Ajoutez une source Navigateur avec l'URL http://localhost:8777/.

  2. Atteindre la page

    Clic droit sur la source, puis Interagir.

  3. La rendre transparente

    Dans l'onglet Réglages de la page, sous Transparence, baissez Fond à 0 %. La scène apparaît au travers, il ne reste que la forme du niveau et les marqueurs. Carte et Panneaux estompent le reste.

La page retient ses réglages par navigateur : la source OBS garde son propre aspect, à part de votre navigateur habituel.

Tailscale Funnel

Une adresse HTTPS publique qui ne change pas : quiconque l'a ouvre la carte, sans compte ni rien à installer de son côté.

  1. Installer Tailscale

    Installez Tailscale sur le PC de jeu et connectez-vous.

  2. Ouvrir le funnel

    Lancez ceci dans un terminal. La première fois, il donne un lien pour activer Funnel sur votre compte :

    tailscale funnel 8777

  3. Partager l'adresse

    Il affiche votre adresse : https:// puis le nom de votre PC sur ts.net. Elle reste la même à chaque fois.

Détails : Tailscale Funnel.

Optionnel : le lancer automatiquement avec la carte
  1. Dans sdk_mods, à côté de helios_tracker.sdkmod, créez un fichier texte nommé helios_tracker.autoexec.ps1.
  2. Collez-y cette ligne : 
    tailscale funnel $env:HELIOS_PORT
  3. Désormais, le tunnel démarre avec la carte, et s'arrête avec elle.

Un tunnel Cloudflare

Un tunnel nommé publie la carte sur votre propre domaine, comme map. suivi de votre domaine, en HTTPS.

  1. Installer cloudflared

    Installez cloudflared sur le PC de jeu (ou, dans un terminal : winget install Cloudflare.cloudflared).

  2. Créer le tunnel

    Dans le tableau de bord de Cloudflare, créez un tunnel et donnez-lui un nom d'hôte sur votre domaine.

  3. Le lancer

    Sur le PC de jeu, avec le nom de votre tunnel :

    cloudflared tunnel run --url http://127.0.0.1:8777 nom-de-votre-tunnel

  4. Partager l'adresse

    Votre nom d'hôte, avec https://. Il reste le même à chaque fois.

Détails : Cloudflare Tunnel.

Optionnel : le lancer automatiquement avec la carte
  1. Dans sdk_mods, à côté de helios_tracker.sdkmod, créez un fichier texte nommé helios_tracker.autoexec.ps1.
  2. Collez-y cette ligne : 
    cloudflared tunnel run --url http://127.0.0.1:$env:HELIOS_PORT nom-de-votre-tunnel
  3. Désormais, le tunnel démarre avec la carte, et s'arrête avec elle. Mettez le nom de votre tunnel.

Un tunnel Cloudflare rapide

Ni compte ni domaine : un programme et une commande.

  1. Installer cloudflared

    Installez cloudflared sur le PC de jeu (ou, dans un terminal : winget install Cloudflare.cloudflared).

  2. Ouvrir le tunnel

    Lancez ceci dans un terminal pendant que la carte tourne, et laissez-le ouvert :

    cloudflared tunnel --url http://127.0.0.1:8777

  3. Partager le lien

    Il affiche une adresse trycloudflare.com : collez-la ici, et partagez le lien obtenu. Chacun garde ses propres réglages avec, même si l'adresse change à chaque démarrage.

    Ou construisez-le à la main : https://helios-tracker.zoolsmith.com/live/?at= suivi de l'adresse du tunnel, sans https://.

Bien pour une soirée, pas pour le lien fixe d'un stream :

  • L'adresse change à chaque démarrage, et Cloudflare propose les tunnels rapides pour des essais, sans garantie.
  • Pendant la première demi-minute après l'ouverture de la page (et après chaque actualisation), les mouvements arrivent par à-coups ; ensuite, c'est fluide.
Ou, sans rien installer : un tunnel SSH

Windows a déjà ssh. Des services gratuits font tourner ces tunnels, par exemple localhost.run. Lancez ceci dans un terminal pendant que la carte tourne, répondez yes la première fois, et collez l'adresse https:// affichée dans la case de l'étape 3 :

ssh -R 80:127.0.0.1:8777 nokey@localhost.run

Ce sont des services tiers, sans lien avec Helios Tracker : leurs offres gratuites sont limitées dans le temps et peuvent changer, et un service peut fermer. Comme pour un tunnel rapide, l'adresse change à chaque fois : partagez-la aussi via le site. S'il ne marche plus, un autre service de tunnel SSH fonctionne de la même façon : vérifiez que son adresse ne contient pas votre IP (certains gratuits le font). Détails : localhost.run.

Plus de 50 spectateurs

C'est au-delà de ce que le mod peut servir : chaque spectateur reçoit chaque mise à jour directement de votre PC, et votre débit montant s'épuise bien avant.

Il faut un relais : un serveur qui reçoit le flux de la carte une fois et le renvoie à chaque spectateur, pour que votre PC ne l'envoie qu'une fois. Ou, pour Twitch, une extension qui affiche la carte dans le lecteur. Les deux demandent de faire tourner votre propre service : Helios Tracker n'en fournit pas.

Avant de partager

  • Quiconque a le lien voit la carte, le nom des joueurs et leur équipement.
  • Arrêtez le tunnel quand vous avez fini.
  • Allow LAN Access n'est pas nécessaire : le tunnel se connecte au PC lui-même.
  • Pourquoi ne pas simplement ouvrir un port sur la box ? C'est possible, mais le lien est alors votre adresse IP : quiconque l'a, et quiconque à qui il le transmet, la connaît, et tant que le port est ouvert, votre PC est joignable par tout internet à travers lui. L'adresse change aussi de temps en temps, et beaucoup de fournisseurs d'accès ne le permettent pas du tout. Un tunnel garde votre IP privée et le lien valable.
  • Chaque spectateur utilise votre débit montant : votre PC envoie à chacun chaque mise à jour, environ 0,6 Mbit/s par spectateur (plus dans les niveaux chargés). Pour le ménager, baissez Updates Per Second dans les options du mod (10 par défaut ; 5 le divise par deux) : la page lisse les mouvements entre deux mises à jour. C'est pour tout le monde, votre propre page aussi.
