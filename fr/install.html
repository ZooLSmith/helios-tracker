Installation

Il vous faut Borderlands 2 sur PC avec le SDK Python. Ensuite, c'est un seul fichier.

  1. Installer le SDK Python

    Le SDK est le gestionnaire de mods sur lequel tournent les mods de Borderlands 2. Téléchargez-le sur sa page des versions, qui renvoie aussi aux instructions d'installation. Helios Tracker demande le SDK actuel (la version 3, avec le menu Mods en jeu). Les anciens mods faits pour l'ancien SDK sont une autre histoire.

  2. Télécharger le mod

    Récupérez helios_tracker.sdkmod sur la page des versions.

  3. Le mettre dans sdk_mods

    Sur Steam : clic droit sur Borderlands 2 dans la bibliothèque, puis Gérer, Parcourir les fichiers locaux.

    Copiez le fichier dans le dossier sdk_mods de l'installation du jeu.

    Borderlands 2\sdk_mods\helios_tracker.sdkmod

  4. L'activer

    Lancez le jeu, ouvrez Mods depuis le menu principal, choisissez Helios Tracker et activez-le. Il le reste pour les sessions suivantes.

  5. Ouvrir la carte

    Dans les options du mod, appuyez sur Open Map in Browser, ou allez à cette adresse dans n'importe quel navigateur du même PC :

    http://localhost:8777/

    Laissez l'onglet ouvert pendant que vous jouez : il vous suit de niveau en niveau tout seul.

Les options du mod, dans le jeu, sont en anglais : Open Map in Browser, Port, Allow LAN Access, Updates Per Second. La page, elle, est en français.

Jouer en coop

Un seul joueur a besoin du mod. Si vous avez le choix, installez-le sur le PC de l'hôte : son jeu sait tout, alors que celui d'un invité ne sait que ce que l'hôte lui envoie.

Chez un invité, il marche quand même, avec moins de choses :

  • l'équipement et les arbres de compétences des autres joueurs ne sont pas disponibles : le jeu ne les envoie pas aux invités, et leurs onglets le disent ;
  • les compétences, les recharges et les récompenses de missions sont seulement les vôtres ;
  • la carte montre ce que le jeu de l'hôte partage avec le vôtre.

Autres façons de l'ouvrir

  • Sur votre réseau local : un téléphone, une tablette, un autre PC
  • Dans OBS, au fond transparent
  • Dans l'overlay Steam

Si la carte ne s'ouvre pas, voir le Dépannage.

Le mettre à jour ou l'enlever

Pour le mettre à jour, remplacez helios_tracker.sdkmod par le nouveau et relancez le jeu. Pour l'enlever, supprimez le fichier. Les options du mod sont enregistrées à part, dans sdk_mods\settings.

Helios Tracker est un mod de fan, ni fait ni approuvé par Gearbox Software ou 2K. Borderlands et ses noms leur appartiennent.
