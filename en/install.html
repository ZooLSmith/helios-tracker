Install

You need Borderlands 2 on PC with the Python SDK. Then it's one file.

  1. Install the Python SDK

    The SDK is the mod manager Borderlands 2 mods run on. Follow its install guide on bl-sdk.github.io. Helios Tracker needs the current SDK (version 3, with the Mods menu in game). Older mods built for the legacy SDK are a different thing.

  2. Download the mod

    Get helios_tracker.sdkmod from the releases page.

  3. Put it in sdk_mods

    Copy the file into the sdk_mods folder of the game's install.

    On Steam, right-click Borderlands 2 in your library, then Manage, Browse local files.

    Borderlands 2\sdk_mods\helios_tracker.sdkmod

  4. Turn it on

    Start the game, open Mods from the main menu, pick Helios Tracker and enable it. It stays on for the next sessions.

  5. Open the map

    In the mod's options, press Open Map in Browser, or go to this address in any browser on the same PC:

    http://localhost:8777/

    Leave the tab open while you play. It follows you from level to level by itself.

Playing co-op

Only one player needs the mod. If you can choose, install it on the host's PC: the host's game knows everything, a client's only what the host sends it.

As a client it still works, with less in it:

  • other players' gear, backpack and skill trees aren't available (the page says why);
  • skills, cooldowns and mission rewards are yours only;
  • the map shows what the host's game shares with yours.

Other ways to open it

  • On your local network: a phone, a tablet, another PC
  • In OBS, with a see-through background
  • In the Steam overlay

If the map won't open, see Troubleshooting.

Updating or removing it

To update, replace helios_tracker.sdkmod with the new one and restart the game. To remove it, delete the file. The mod's options are saved apart, in sdk_mods\settings.
