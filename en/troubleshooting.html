Troubleshooting

When the map won't open, check these in order.

Is the mod enabled?

The server only runs while the mod is on: open Mods in the game and check Helios Tracker is enabled.

Is the port taken?

The map uses port 8777. If another program already has it, the server can't start: change Port in the mod's options, and the server restarts at once on the new one. Update your bookmarks and OBS sources to match.

From another device?

Check LAN access is on, the device is on the same network, and the firewall lets the game through.

Still stuck?

Everything the mod prints also goes to Binaries\Win32\Plugins\unrealsdk.log in the game's folder. Attach it to an issue.
