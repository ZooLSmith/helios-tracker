# Helios Tracker

A live map of your Borderlands 2 game in the web browser: the level you're in, from the game's own map, with
players, enemies, loot and missions moving on it as you play. A mod for the Borderlands 2 Python SDK.

**Not published yet.** The mod isn't released and its code isn't public.

The site, with the install guide once it's out: <https://helios-tracker.zoolsmith.com> (the `documentation` branch).

Helios Tracker is a fan-made mod, not made or endorsed by Gearbox Software or 2K. Borderlands and its names belong
to them.
