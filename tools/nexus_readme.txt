Helios Tracker {version}
A live map of the current level of Borderlands 2 (and The Pre-Sequel) in your web browser: the game's own map with
players, enemies, NPCs, vehicles and loot on it - on a second screen, a phone, in OBS or in the Steam overlay.

INSTALL
1. Install the Python SDK if you haven't: https://bl-sdk.github.io/
2. Put helios_tracker.sdkmod in your game's sdk_mods folder (with the SDK's other .sdkmod files). Don't unzip it.
3. Start the game: in the Mods menu, Helios Tracker -> Open Map in Browser (or open http://localhost:8777/).

The full guide - phones and other PCs, OBS, sharing the map: https://helios-tracker.zoolsmith.com/

UPDATE
Mods menu -> Helios Tracker -> Check for Updates (or turn on Automatic Updates there).

REMOVE
Delete helios_tracker.sdkmod and the .helios_tracker folder next to it, in sdk_mods.

Source code and releases: https://github.com/ZooLSmith/helios-tracker - GPL-3.0.
