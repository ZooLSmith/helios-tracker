HELIOS TRACKER

Install

You need Borderlands 2 or Borderlands: The Pre-Sequel on PC, with the Python SDK. Then it's one file. Playing Borderlands ? See below.

  1. Install the Python SDK

    The SDK is the games' mod manager. Download it from its releases page, which also links to the install instructions. Helios Tracker needs the current one (version 3, with the Mods menu in game).

  2. Download the mod

    Get helios_tracker.sdkmod from the releases page.

  3. Put it in sdk_mods

    On Steam, right-click the game in your library, then Manage, Browse local files.

    Copy the file into the sdk_mods folder of the game's install.

    Borderlands 2\sdk_mods\helios_tracker.sdkmod
BorderlandsPreSequel\sdk_mods\helios_tracker.sdkmod

    Playing more than one? Put a copy in each game's sdk_mods.

  4. Turn it on

    Start the game, open Mods from the main menu, pick Helios Tracker and enable it. It stays on for the next sessions.

  5. Open the map

    In the mod's options, press Open Map in Browser, or go to this address in any browser on the same PC:

    http://localhost:8777/

    Leave the tab open while you play. It follows you from level to level by itself.

Borderlands (experimental)

Helios Tracker also runs in Borderlands, the original and the Game of the Year Enhanced edition. It's newer and less tested than the other two games.

The SDK is its own build: get it from its releases page. The mod is the same helios_tracker.sdkmod, installed the same way.

Something wrong or missing? Open an issue and say which edition you play.

Playing co-op

Only one player needs the mod. If you can choose, install it on the host's PC: the host's game knows everything, while a client's game only knows what the host sends it.

As a client it still works, with less in it:

  • other players' gear and skill trees aren't available: the game doesn't send them to clients, and their tabs say so;
  • skills, cooldowns and mission rewards are yours only;
  • the map shows what the host's game shares with yours.

Other ways to open it

  • On your local network: a phone, a tablet, another PC
  • In OBS, with a see-through background
  • In the Steam overlay

If the map won't open, see Troubleshooting.

Updating or removing it

To update, press Check for Updates in the mod's options. If there's a new version, the game asks before downloading it, then offers to reload the mod right away: no need to restart the game.

Or turn on Automatic Updates (off by default): at most once a day, when the mod starts, a new version installs and reloads by itself, and the game says so at the bottom left of the screen.

To remove it, delete helios_tracker.sdkmod and the .helios_tracker folder next to it. The mod's options are saved apart, in sdk_mods\settings.
