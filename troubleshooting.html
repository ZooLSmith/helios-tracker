Troubleshooting

When the map won't open, check these in order.

Is the mod enabled?

The server only runs while the mod is on: open Mods in the game and check Helios Tracker is enabled.

Is the port taken?

The map uses port 8777. If another program already has it, the server can't start: change Port in the mod's options, and the server moves to the new one when you leave the menu. Update your bookmarks and OBS sources to match.

From another device?

Check that Allow LAN Access is on, the device is on the same network, and the firewall lets the game through: see your local network.

A translation is wrong?

Wrong, clumsy or missing words, on this site, on the map's page or in the mod's options: open an issue with the language, the page and what it should say. Names from the game (items, skills, places) come from the game itself.

Still stuck?

Everything the mod prints also goes to Binaries\Win32\Plugins\unrealsdk.log in the game's folder: its last lines usually say what went wrong.
